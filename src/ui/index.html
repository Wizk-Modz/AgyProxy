🔌 Hướng dẫn tích hợp Client

AgyProxy tương thích chuẩn OpenAI API. Bạn có thể sử dụng bất kỳ client hoặc thư viện nào hỗ trợ endpoint OpenAI tùy chỉnh.

1. Cấu hình Cline / Roo Code / Claude Dev

Provider: OpenAI Compatible Base URL: http://localhost:8080/v1 API Key: any-string (ví dụ: sk-antigravity) Model ID: gemini-2.5-pro (hoặc claude-3-7-sonnet)

2. Cấu hình Cursor AI

Vào Cursor Settings -> Models -> OpenAI API Key: Bật "Override OpenAI Base URL" URL: http://localhost:8080/v1 API Key: sk-antigravity

3. Python SDK (openai)

from openai import OpenAI client = OpenAI( base_url="http://localhost:8080/v1", api_key="sk-antigravity" ) res = client.chat.completions.create( model="gemini-2.5-pro", messages=[{"role": "user", "content": "Xin chào!"}] ) print(res.choices[0].message.content)

4. Kiểm tra nhanh bằng curl

curl http://localhost:8080/v1/chat/completions \ -H "Content-Type: application/json" \ -H "Authorization: Bearer sk-antigravity" \ -d '{ "model": "gemini-2.5-pro", "messages": [{"role": "user", "content": "Xin chào"}] }'
